# Same-page JIT links and syscall continuations — 2026-11-27

Baseline JIT: `f10a1597574d3b97b5d72b6c7d1d9d4a18ae5c8b`.
The same expanded `cpu-boundary` example runs against independently saved old/new
release binaries on the existing ARM64 Linux VM. Incremental builds are disabled;
source timestamp rollback cannot substitute the old executable for the new one.
Each number is five-pass median after one full warm-up pass. These are CPU-only
microbenchmarks, excluding Linux syscall handlers, JNI and Android lifecycle.

| Fixed workload | Old JIT | Linked JIT | Old/new |
| --- | ---: | ---: | ---: |
| integer-loop | 4.394 ms | 3.511 ms | 1.25x |
| svc-round-trip | 0.679 ms | 0.623 ms | 1.09x |
| svc-only | 0.646 ms | 0.592 ms | 1.09x |
| svc-continuation | 1.140 ms | 0.875 ms | 1.30x |

The added continuation workload repeatedly resumes at the post-SVC guest PC,
executes a fixed branch back to ADD+SVC, and simulates a committed return value.
Each measured pass contains 100,000 entries; a completed entry retires exactly
three guest instructions. The integer workload remains 16 × 1,048,576 guest
instructions per pass. Single-block SVC entries keep their lightweight ABI to
avoid chain-frame overhead when no chain is executed.

Validation:

- ARM64 Linux: two native ABI/epoch/eviction tests, sixteen differential/contract
  tests, scoped JIT/memory all-target Clippy and Android core link probe passed.
- A warmed 10,000-instruction two-word loop uses one native entry and 4,999
  successful native links. Budgets 0/1/2/3/63/64/65/4097/10000 match the canonical
  interpreter's complete architectural state.
- A second worker writes SVC into a live RWX code loop. The existing release /
  acquire code epoch stops the executing native chain and revalidates the code.
- Tests cover source changes/permissions/unmap, cross-page non-linking, target
  eviction before munmap, generation rejection, current syscall arguments,
  simulated returns/restarts, adjacent SVC stops, and capability-declining legacy
  memory embeddings. No test relies only on successful cross-compilation.
- Apple: scoped tests/Clippy and iOS interpreter compile check passed. The shared
  memory hook adds no fields, ordinary access checks, counters or dependencies.
  iPad does not acquire a dependency on the optional JIT crate.

Android probe flag bit 4 requires actual native block links and cached syscall
resumption, in addition to the existing direct-SVC flag. The JNI report ABI stays
40 bytes and its original retirement/native-instruction fields describe the
initial probe. Android device app-UID execution and full Session integration
remain separate milestones.
