# FUSE 同步性能与配对交付（2026-11-25）

本轮接续此前累计的 FUSE 实现、原系统调用续接、映射与传输调用方、写回有界失败和事件生产者修复，完成同步性能检查及主线交付。完整 FUSE 路线图及其他领域仍按产品仓库清单推进；本报告不代表全部 gVisor、物理 iPad 或 HVF guest 验收。

## 同步成本及实现

真实 passthrough daemon 的最后一次时间回写会调用 `utimensat`。此前 `set_times_flags` 对 tmpfs 文件也调用 VFS 全局 `checkpoint`，连带提交无关 overlay 和磁盘根目录。独立诊断产物中，该 SETATTR 的回复耗时 8.114 ms；原磁盘池单次排队通常约 2–8 µs，快照处理合计不足 0.5 ms。这些带日志的观测用于定位，不能替代正式性能数据。

新增 `FsHandle::checkpoint_metadata`，权限、所有权和时间修改均保留原目标文件系统，经路径或原 OFD 提交，卸载后的 FD 继续使用原 mount。临时、无链接 inode 不发布无关命名空间；磁盘／overlay 目标保留原持久化步骤和失败回滚。没有新增协调或服务线程，没有关闭 WRITEBACK_CACHE，也没有提前返回 FSYNC。

新回归注入磁盘根目录提交失败，验证 tmpfs 路径、FD 和卸载后的 chmod／chown／utimensat 均成功，根目录 manifest 不变；同轮磁盘文件仍返回失败并恢复原属性。Apple／Linux 均通过。
